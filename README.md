# 卡了个皮巴拉

卡皮巴拉主题的「羊了个羊」式三消闯关游戏：**12 章 × 3 关共 36 关**，每 3 关提升层数与难度，关卡堆叠和章节背景实时生成。通关会掉落 R / SR / SSR 卡皮巴拉卡片，重复卡化为碎片，碎片可以合成普通卡或炫彩卡。带闯关用时排行榜与 24 项成就。

![冒险地图](preview.png)

![炫彩卡奖励](preview-card.png)

12 张卡拥有各自独立的服装、帽子和道具：草帽、墨镜、雨衣、针织帽、睡帽、花冠、贝雷帽、温泉毛巾、太空头盔、王冠、彩虹卫衣……不是同一张卡皮巴拉换颜色。

![十二张卡皮巴拉卡册](preview-cards.png)

## 直接开玩

- **单文件离线版**：双击 [`capybara-sheep.html`](capybara-sheep.html)，无需安装、无需联网。
- **源码版**：打开 [`index.html`](index.html)（需要同目录下的 `styles.css` 和 `game.js`）。

建议使用 Chrome / Edge / Safari 等现代浏览器。桌面、平板和手机竖屏均已适配，所有素材（SVG、音效、卡面）均为内联/实时渲染，无外部资源。

## 大冒险内容

### 闯关地图

- 12 个章节，每章 3 个关卡，共 36 关。
- 地图节点会显示通关星级：1-3 星，可反复挑战刷新最好成绩。
- 每章拥有独立主题和配色，地图路径、太阳、云朵和装饰位置实时生成。
- 章节按顺序解锁；通关每章第 3 关后进入下一章。

| --- | --- | --- | --- |
| 第 1 章 | 4 层 | 36 / 39 / 42 | ★☆☆☆☆ |
| 第 2 章 | 5 层 | 42 / 45 / 48 | ★☆☆☆☆ |
| 第 3 章 | 6 层 | 48 / 51 / 54 | ★★☆☆☆ |
| 第 4 章 | 7 层 | 54 / 57 / 60 | ★★☆☆☆ |
| 第 5 章 | 8 层 | 60 / 63 / 66 | ★★★☆☆ |
| 第 6 章 | 9 层 | 66 / 69 / 72 | ★★★☆☆ |
| 第 7 章 | 9 层 | 72 / 75 / 78 | ★★★★☆ |
| 第 8 章 | 9 层 | 78 / 81 / 84 | ★★★★☆ |

- 每一关都按章节种子实时生成牌堆布局，同一关重试时布局保持一致。
- 章节背景由主题色板、随机云朵/太阳位置和装饰元素共同实时生成。

### 卡牌收集

- 12 张卡皮巴拉卡：4 张 R、4 张 SR、4 张 SSR。
- 每张卡都是**独立造型**：不同的毛色、服装、帽子、手持道具和表情（例如小鸭跟班的雨衣、温泉泡泡的毛巾、星河旅人的太空头盔、卡皮巴拉之王的王冠）。
- 每张卡都有**普通卡**和**炫彩卡**两种形态；炫彩卡有旋转彩虹边框和流光效果。
- 每次通关都会获得一张卡：
  - 新卡：直接解锁并加入卡册。
  - 重复卡：转化为碎片。
  - 小概率直接掉落炫彩卡。
- 1-3 星评价影响碎片数量：1 星 +4、2 星 +7、3 星 +10；重复卡还会按稀有度额外给碎片。
- 碎片为通用卡皮碎片：
  - 合成未解锁普通卡：R 30 / SR 60 / SSR 100 碎片。
  - 将普通卡升级为炫彩卡：R 100 / SR 180 / SSR 280 碎片。
- 通关后弹出**以卡片为绝对视觉中心**的浮窗：大卡居中、光环背景、翻卡动画，稀有度/星级/碎片明细都排在卡片下方。

### 三消手感

- 点满 3 张同款会**立即消除**，不用等消除动画播完才能继续点。
- 卡槽、进度和可点状态同步更新；连点、快速通关不会卡住。
- 消除动画使用独立的幽灵图层播放，不阻塞下一次点击。
- 被上层压住的贴纸会变暗；洗牌后保证牌堆仍有解。
- 卡槽 6 格全是不同图案时，洗牌会提示先撤销，避免浪费道具。

## 玩法

1. 只有没被上层压住的贴纸才能点。
2. 点中的贴纸进入卡槽，相同图案凑满 3 张立即消除。
3. 卡槽最多 7 格，放满且未凑成三连即失败。
4. 道具：
   - 撤销 3 次
   - 洗牌 2 次（按当前堆叠关系重新生成有解分配）
   - 提示 3 次
5. 通关按用时任 1-3 星（每张牌约 1.6 秒基准），并获得卡片/碎片。
6. 在地图或卡册里查看收集进度，用碎片合成缺少的卡。
7. 顶部奖杯按钮看用时排行榜，奖牌按钮看成就进度。

## 技术实现

- 纯 HTML / CSS / JavaScript，无任何第三方依赖。
- SVG 图标、卡面、地图装饰全部内联或实时生成。
- Web Audio 合成音效，可静音。
- `localStorage` 存档：关卡解锁、星级、卡片、碎片、用时纪录、成就、声音设置。
- 棋盘网格随视口切换：竖屏 6×8（牌块 62px），桌面 9×8（牌块更大视野）；`board-stage` 的 `aspect-ratio` 由 `--grid-cols/--grid-rows` 驱动，牌块固定 1:1，保证不溢出不留白。
- 关卡生成：
  1. 按层数分配贴纸数量，在收缩范围内随机落点，保证同层不重叠。
  2. 随机剥离出一个合法点选顺序。
  3. 每 3 张一组分配同一图案，保证至少存在一条通关路径。
- 洗牌会重新计算当前牌堆的剥离顺序，先补齐卡槽已有图案，再分组，保证洗牌后有解；洗牌后旧快照作废（撤销不会回滚牌面）。
- 响应式适配：1440×900、1280×800、1024×768、768×1024、390×844、375×667、320×568 均已实测无页面溢出。
